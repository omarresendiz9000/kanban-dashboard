# Kanban Dashboard

A full-stack Kanban web application built as a learning and portfolio project.

## Goals

The application will support:

- Kanban boards
- Work items
- Drag-and-drop workflow
- Priorities and assignments
- WIP limits
- Cycle time
- Lead time
- Throughput
- Aging work items
- Workflow analytics
- User authentication and authorization

## Technology Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Java 17
- Spring Boot
- Maven

### Database
- H2 for initial development
- PostgreSQL later

### Development Tools
- Visual Studio Code
- Git
- GitHub
- GitHub Copilot
- Postman
- DBeaver
